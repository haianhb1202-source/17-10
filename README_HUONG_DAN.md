# Lesson09

Dự án ASP.NET Core MVC, mục tiêu .NET 10.

## Mở dự án
1. Mở `Lesson09.slnx` bằng Visual Studio 2026 hoặc mở `Lesson09.csproj`.
2. Kiểm tra SQL Server trong `appsettings.json` và `Models/BookStoreDbContext.cs`.
3. Cơ sở dữ liệu cần có tên `BookStoreDB`; chuỗi kết nối mẫu trong dự án dùng instance `SQL2019`. Hãy sửa lại cho phù hợp với SQL Server trên máy bạn.
4. Khôi phục NuGet packages rồi chạy bằng F5.

Lưu ý: Dự án đã được đổi tên toàn bộ; chưa thể xác nhận build trong môi trường này nếu không có .NET SDK và SQL Server.
